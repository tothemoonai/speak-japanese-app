这是一个专注于 IT 日语口语的学习软件。

页面 1，Dashboard页：首页包括学习报告，课本列表，

页面 2，课本选择页：用户可以选择日语口语练习课本。每一本课本有一个课本卡片，显示课本的名字，难度（N，N2, N1），总共包含了的课数、学习进度、已经完成的学习内容等等。

页面 3，学习报告页：可以查看总览、本周、当日以及任意日期的的学习报告。包括练习次数、学习时长以及平均分数。

页面 4， 课程列表,是一本课本每一课的列表.这个课程有个课程卡片.包含课程的名称、主题、包含的对话数量以及学习进度.

页面 5， 课程内容。包含课程的对话内容。搭配的角色，用户可以根据角色来选择对话内容。也有按钮可以让显示中文或日文。也包括学习进度，练习了多少次？练习了多少句。

页面 6，练习页面。一课的练习页面。用户可以选择角色，选择句子，可以播放录音（TTS实现），可以录音，并实现自动识别语音内容。软件会自动给出一个评估分数。

提供温馨和科技两种方案。两种方案分别有白天和黑夜两种配色。
