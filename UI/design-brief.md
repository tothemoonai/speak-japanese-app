# IT日语 — APP UI 设计需求文档

> 本文档为 UI 设计师提供完整的项目信息。请基于此文档设计全新的移动端 UI 方案。

---

## 总述

### 产品简介

**IT日语** 是一款面向 IT 从业者的日语口语学习 APP。用户通过选择课程中的角色，朗读日语对话句子，系统利用 AI 语音识别实时评估发音准确度、流利度和情感表达，帮助用户提升日语会话能力。

### 目标用户

- **IT 工程师**: 在日企工作或计划赴日，需要职场日语会话能力
- **日语学习者**: 备考 JLPT N5-N1，需要口语实战练习
- **留学生**: 准备赴日留学，需要日常/学术场景会话
- **兴趣用户**: 对日本文化感兴趣，希望入门基础会话

### 核心功能

1. **AI 智能评估** — 多维度打分：准确度、发音、流利度、情感、自由度
2. **情景对话练习** — 真实职场/生活场景的角色扮演
3. **语音识别** — 实时语音转文字，对比标准答案
4. **学习追踪** — 完整的学习数据统计和进度管理

### 内容层级

```
书本 (Book) — 按JLPT等级分类 (N5→N1)
  └── 课程 (Course) — 一个情景对话课
        ├── 角色 (Character) — 对话中的人物
        └── 句子 (Sentence) — 对话中的每一句话
              └── 练习记录 (Practice) — 用户的练习数据
```

### 评分系统

- **总分**: 0-100 分
- **等级**: S (95+) / A (85+) / B (70+) / C (50+) / D (<50)
- **五个维度**: 准确度、发音、流利度、情感表达、自由度（各 0-100）

### 难度体系

- **书本**: N3（中级）→ N2（高级）→ N1（精通）
- **用户等级**: beginner（初级）→ intermediate（中级）→ advanced（高级）
- **句子难度**: easy / medium / hard

### 技术约束

| 项目 | 说明 |
|------|------|
| 平台 | Android APP（Capacitor 混合应用） |
| 框架 | Next.js 16 + React 18 |
| 样式 | Tailwind CSS + shadcn/ui |
| 图标 | Lucide React |
| 设计尺寸 | 375px 宽度为基础，适配主流 Android 手机 |
| 必须支持 | 深色模式、中日双语、日文假名注音/罗马音 |
| 触摸目标 | 最小 44×44px |
| 安全区域 | 需考虑刘海屏/底部导航栏 safe-area |

### 已有 UI 组件

Button, Card, Input, Label, Badge, Progress, Tabs, Dialog, Table, Select, Textarea, AlertDialog, Tooltip, ScrollArea, Toast (Sonner)

### 当前 UI 存在的主要问题

| 优先级 | 问题 | 位置 | 影响 |
|--------|------|------|------|
| **高** | 移动端触摸目标过小 | 练习页按钮、录音控制 | 误触率高 |
| **高** | 录音/识别状态反馈不足 | 录音器 | 用户不确定系统状态 |
| **高** | 页面间导航不一致 | 全局 | 学习成本高 |
| **中** | 长页面滚动疲劳 | 课程详情、设置、帮助 | 信息查找困难 |
| **中** | 数据可视化过于简单 | 报告页 | 无法展示学习趋势 |
| **中** | 角色视觉区分度低 | 课程详情 | 多角色难以区分 |
| **中** | 首次使用到练习路径过长 | 全局导航 | 6次点击才能开始 |
| **中** | 空状态设计单薄 | 列表页 | 用户困惑 |
| **低** | 骨架屏加载不统一 | 全局 | 加载体验不一致 |
| **低** | 微交互不足 | 全局 | 界面静态感 |

### 设计风格方向（供参考，不设限）

- **A**: 日式极简（无印良品风格）— 留白、自然、温润
- **B**: 科技未来感 — 霓虹、暗色、动效

设计师也可以提出全新方向。

**页面说明**:
用户登录后看到的主页面。展示学习数据概览、快捷操作入口和最近学习的课程。这是用户每次打开 APP 的默认落脚点。

## 页面 8：练习页 ⭐ 核心页面

**路由**: `/practice/[id]`
**是否需要登录**: 是

**页面说明**:
**这是用户使用时间最长、体验最关键的页面。** 用户在此进行日语口语练习：看句子 → 录音 → 获得评估。需要重点设计交互状态和反馈体验。

**需要包含的区域**:

| 区域 | 内容说明 |
|------|----------|
| 顶部栏 | 返回按钮 + 课程名 + 句子列表入口 |
| 进度指示 | 当前句子序号 / 总句子数 + 进度条 |
| 角色选择 | 按钮组：选择扮演哪个角色（如：田中 / 铃木） |
| 句子展示 | **大字日文** + 中文翻译 + 假名注音 + 罗马音 |
| 标准音播放 | 播放该句的标准发音（TTS） |
| 录音按钮 | **页面最核心的交互元素**，需要特别大且醒目 |
| 识别结果 | 显示语音识别出的文字（对比标准答案） |
| 评估结果 | 得分 + 等级 + 维度分数 + 反馈 |
| 导航控制 | 上一句 / 下一句 |

**录音器需要设计的交互状态**:

| 状态 | 视觉反馈 |
|------|----------|
| 空闲 | 等待用户点击录音 |
| 录音中 | 脉冲动画 + 录音时长 + 波形效果 |
| 识别中 | 加载动画 + "正在识别..." 提示 |
| 识别完成 | 显示识别文本 + 自动触发评估 |
| 评估中 | 加载动画 + "AI评估中..." 提示 |
| 评估完成 | 显示评估结果（分数+等级+反馈） |
| 错误 | 红色提示 + 重试按钮 |

**评估结果数据**:
- `overall_score`: 总分 (0-100)
- `grade`: S / A / B / C / D
- `accuracy_score`: 准确度 (0-100)
- `pronunciation_score`: 发音 (0-100)
- `fluency_score`: 流利度 (0-100)
- `emotion_score`: 情感 (0-100)
- `freedom_score`: 自由度 (0-100)
- `feedback.highlights[]`: 亮点列表
- `feedback.issues[]`: 问题列表
- `feedback.suggestions[]`: 建议列表

**练习模式**:
- `standard`: 标准模式 — 逐句练习
- `shadow`: 跟读模式 — 跟着标准音读
- `free`: 自由模式 — 不限内容

**用户目标**: 专注练习日语口语，获得即时反馈

**设计重点**:
- 录音按钮要大、醒目、状态清晰
- 评估结果展示要直观有成就感
- 翻页操作要流畅自然
- 减少视觉噪音，让用户专注于句子内容

## 设计交付要求

### 需要交付的内容

1. **设计系统**
   - 色彩体系（主色、辅助色、语义色、深色模式）
   - 字体规范（中文/日文/英文、字号层级）
   - 间距系统
   - 圆角、阴影、边框规范
   - 基础组件变体（按钮、卡片、标签、输入框等）

2. **全部 11 个页面的高保真设计稿**
   - 基于 375px 宽度
   - 深色模式版本（至少核心页面：首页、仪表板、练习页、课程详情）

3. **关键交互状态设计**
   - 录音器 7 种状态（空闲/录音中/识别中/识别完成/评估中/评估完成/错误）
   - 评估结果展示方式
   - 加载状态、空状态、错误状态

4. **设计标注**
   - 关键尺寸、间距、颜色值
   - 交互动画说明

### 重点页面（需特别用心）

1. ⭐ **练习页** — 用户停留最久，体验最关键
2. **首页** — 品牌第一印象
3. **仪表板** — 每天看到的第一个页面
4. **课程详情** — 信息密度最高
